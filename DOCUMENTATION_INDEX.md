## Key Information Quick Reference

### Server Details
- **URL:** http://127.0.0.1:3000
- **Port:** 3000
- **Host:** 127.0.0.1 (localhost)
- **Framework:** FastAPI
- **Server:** Uvicorn

### API Endpoints
- `/` - Main app
- `/health` - Server status
- `/api/recommend-gemini` - AI recommendations
- `/api/save-feedback` - Save user feedback
- `/dashboard-data` - Dashboard analytics
- Plus 6 more endpoints (see comprehensive guide)

### Main Features
- ✅ User authentication
- ✅ Personalized recommendations (via Gemini AI)
- ✅ 10 break routine types
- ✅ Dashboard with 4 charts
- ✅ Feedback system
- ✅ Mobile responsive design

### Break Routine Types
1. Physical
2. Mindfulness
3. Outdoor Activity
4. Social Interaction
5. Creative Activity
6. Hydration & Nutrition
7. Dance & Music
8. Brain Games
9. Gratitude & Journaling
10. Pet Care & Animals

### Technologies
- **Backend:** FastAPI, Python 3.8+, pandas
- **Frontend:** HTML5, Tailwind CSS, Chart.js
- **Styling:** Dark theme (teal #0D9488, orange #F97316)
- **API:** Google Gemini with exponential backoff retry

### Mobile Breakpoints
- Mobile: <480px
- Mobile+: 480-767px
- Tablet: 768-1023px
- Desktop: ≥1024px
